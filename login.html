For the Data Keeper: how to create the two logins
  1. In Supabase open Authentication > Users > Add user. Create one user for the Mine Manager and one for the Maintenance Engineer. Give each an email and a password. Tick Auto Confirm User.
  2. Open database/06-set-login-roles.sql, put the two emails in it, and run it in the SQL Editor. This tells the tool which login is the manager and which is the engineer.
  3. Optional: run database/07-optional-lock-machines.sql. Without it, the login only hides the screens. With it, the database itself refuses changes from anyone who is not logged in.
